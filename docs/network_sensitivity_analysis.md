# 鉄道網トポロジーのパラメータ感度分析：設計指針および検証結果

本稿では、鉄道ネットワークモデルにおける構造中心性（媒介中心性・調和中心性）のパラメータ依存性を単変量摂動法（One-At-a-Time: OAT）により検証し、基準パラメータ設定の妥当性と時間制限（カットオフ）導入の有効性を論証する。

## 1. 実験計画とパラメータ空間

### 1.1 目的と分析条件
経路探索および中心性指標は、乗換許容距離や各種ペナルティ時間の設定値に依存する。評価結果が恣意的なパラメータ選択によるものではないことを示すため、基準モデル（`baseline`）から1変数ずつ摂動させるOAT感度分析を以下の2条件（独立した2つのSQLiteデータベース）で実施する。

* **時間制限なし（全域モデル）**: `network_sensitivity_unbounded.sqlite`（`time_cutoff_s = NULL`、到達可能な全駅ペアを対象）
* **時間制限あり（120分カットオフモデル）**: `network_sensitivity_cutoff.sqlite`（`time_cutoff_s = 7200` 秒、所要時間120分以内の駅ペアのみを対象）

### 1.2 シナリオ設定一覧
`shared/params.py`（`NetworkParams`）で定義されるパラメータ空間と全7シナリオの設定を以下に示す。

### 1.3 速度・迂回パラメータを固定する数理的根拠
経路 $P$（軌道リンク集合 $P_{\text{rail}}$、乗換リンク集合 $P_{\text{trans}}$）の所要時間コスト $C(P)$ は次式で定義される（ただし $d_{\text{walk}}(e) \le D_{\text{trans}}$、新幹線は国土数値情報 `provider_type_code = '1'` により識別し $v_{\text{rail}}(e) = v_{\text{shinkansen}}$、その他は $v_{\text{train}}$ を適用）。

$$
C(P) = \sum_{e \in P_{\text{rail}}} \left( \frac{d_{\text{rail}}(e)}{v_{\text{rail}}(e)} + T_{\text{stop}} \right) + \sum_{e \in P_{\text{trans}}} \left( \frac{\alpha \cdot d_{\text{walk}}(e)}{v_{\text{walk}}} + T_{\text{pen}} \right)
$$

1. **巡航速度（$v_{\text{train}}, v_{\text{shinkansen}}$）と時間ペナルティの双対性**:
   最短経路集合および中心性順位は、全リンクコストの正の定数倍に対して不変（正斉次性）である。路線種別ごとの基準速度比（新幹線 $200\text{ km/h}$ 対 在来線 $50\text{ km/h}$）を固定した場合、走行速度全体のスケール変動は、軌道走行時間に対する $T_{\text{stop}}$ および $T_{\text{pen}}$ の相対重みを変化させる操作と数理的に等価であり、両ペナルティの摂動実験によって網羅される。
2. **歩行速度（$v_{\text{walk}}$）と迂回係数（$\alpha$）の共線性・包含関係**:
   両者は常に単一の比 $\alpha / v_{\text{walk}}$ としてのみ作用するため完全に共線である。また、同一座標乗換（$d_{\text{walk}} = 0$）では影響せず、異駅間徒歩（最大 $600\text{ m}$）における実用上の速度変動も数十秒にとどまるため、$T_{\text{pen}} \in [90\text{ s}, 300\text{ s}]$ の摂動範囲に完全に包含される。
3. **実質的自由度への集約**:
   以上より、ネットワーク位相と最短経路選択を実質的に支配する3変数（$D_{\text{trans}}, T_{\text{pen}}, T_{\text{stop}}$）にOAT摂動を集約する。

## 2. 定量的評価指標

1. **スピアマン順位相関係数（$\rho$）**: 全駅（10,230駅）における基準順位 $R_0$ と摂動順位 $R_k$ の相関を測定する。$\rho \ge 0.95$ を「極めて高い頑健性（巨視的評価構造が不変）」の判定基準とする。
2. **Top-$K$ Jaccard類似度（$J$）**: 上位 $K=50$ 駅の集合 $S_0, S_k$ について重複率 $J(S_0, S_k) = |S_0 \cap S_k| / |S_0 \cup S_k|$ を算出し、最上位要衝群の保存性を評価する。
3. **最大順位変動量（$\Delta R$）**: $\Delta R_i = R_{0, i} - R_{k, i}$（正値は順位上昇、負値は下降）の絶対値が大きい特異駅を抽出し、特定の接続リンクやコスト条件に依存する局所的な構造変化を特定する。

## 3. 可視化・検証出力の基本構成

1. **順位散布図（Rank-Rank Scatter Plot）**: 基準順位と摂動順位の対角線（$y = x$）への集束度と外れ値を可視化。
2. **上位要衝駅順位推移表（Top-$K$ Transition Table）**: 主要ターミナルにおけるシナリオ間の順位推移を一覧化。
3. **空間的変動分布図（Spatial Sensitivity Map）**: 順位変動量 $|\Delta R|$ を地図上にプロットし、変動が集中する路線・地域を特定。

### 5.2 上位結節点の保存性（Top-50 Jaccard類似度）

| 対象シナリオ（対 `baseline`） | パラメータ設定 ($D_{\text{trans}}$ / $T_{\text{pen}}$ / $T_{\text{stop}}$) | 媒介中心性 Jaccard (重複駅数) | 調和中心性 Jaccard (重複駅数) |

* **Top-50 Jaccard類似度の数値特性と評価**:
  1. **数式上の分母膨張効果と実質重複率**: 固定サイズ $K=50$ における Jaccard 類似度は $J = c / (100 - c)$（$c$ は重複駅数）となるため、境界上の数駅が入れ替わるだけで分母が倍増的に膨張する。見かけ上 $0.7544 \sim 0.8868$ に留まるシナリオであっても、実質的な重複駅数は **43〜47駅（一致率 86%〜94%）** に達しており、最上位結節点群の大勢は強固に保存されている。
  2. **都心複数路線ノードの密集と境界近傍での微幅変動**: 本モデルは路線別駅ノード（全10,230駅）を単位とするため、調和中心性の上位には東京・大手町・銀座・日本橋等の都心各線ノードが密集し、第40位〜第60位の評価値差は $1.6\%$ 未満に収まる。例えば調和中心性で最小値（$J=0.7857$、44/50一致）となる `penalty_90s` において50位圏外へ出た6駅（銀座線・銀座 #41$\rightarrow$#51、京橋 #31$\rightarrow$#52、東西線・日本橋 #43$\rightarrow$#52、三越前 #35$\rightarrow$#58、浜松町 #49$\rightarrow$#64、霞ヶ関 #47$\rightarrow$#66）や、媒介中心性 `penalty_300s`（$J=0.7544$、43/50一致）で圏外となった7駅（三宮 #50$\rightarrow$#55、浜松 #47$\rightarrow$#58、掛川 #46$\rightarrow$#62、新富士 #49$\rightarrow$#63、および新横浜乗換抵抗増の影響を受けた横浜線・菊名 #38$\rightarrow$#79、大口 #43$\rightarrow$#98、東神奈川 #44$\rightarrow$#103）はいずれも**全国上位1%圏内（#51〜#103）での微幅な順位入れ替わり**であり、構造的な順位崩落ではない。
  3. **`trans_800m` のみ極めて高い一致度を示す理由**: 都心主要ターミナルの乗換距離はすべて基準値（600m）以内に収まっているため、上限を800mへ緩和しても都心最上位群の接続構造は変化せず、Top-50 の顔ぶれがほぼ完全に維持される（媒介 49/50、調和 50/50）。

### 5.3 120分カットオフ下における順位変動の特性と結論
* **上位拠点の構成と安定性**: 媒介中心性では、新幹線と巨大都市圏在来線網が結節する広域ゲートウェイ駅（上野 #1、大宮 #2、品川 #3、京都 #4、新横浜 #5、東京 #6〜#7、名古屋 #8 等）が最上位を占め、調和中心性でも東京・神田・有楽町などの首都圏コア駅群が上位を堅持した。
* **局所的変動メカニズムの一貫性**: 大幅な順位変動を示した特異駅は、`trans_300m` における東京（京葉線: #905 $\rightarrow$ #9854）や新静岡（静岡清水線: #1868 $\rightarrow$ #9854）、`trans_800m` における国際会館（烏丸線: #9887 $\rightarrow$ #2134）や南魚崎（六甲アイランド線: 調和 #10187 $\rightarrow$ #3790）、`stop_60s` における二俣新町（京葉線: #1105 $\rightarrow$ #9888）など、全域モデルと同一の局所的トポロジー要因によって説明される。したがって、120分カットオフモデルにおいても基準パラメータ（`600m / 180s / 30s`）の妥当性は揺るがない。

## 6. 時間制限（カットオフ）の有無が感度分析の結論に与える影響

第4章（時間制限なし）および第5章（120分カットオフ）の検証結果を対比し、時間制限の導入がOAT感度分析の結論および各中心性指標の評価構造に与える影響を整理する。

### 6.1 パラメータ頑健性に関する結論の不変性と安定性向上

| 評価項目 | 時間制限なし（全域モデル） | 時間制限あり（120分カットオフ） | 比較結論 |
| :--- | :---: | :---: | :--- |
| **媒介中心性 $\rho$ 範囲** | $0.9617 \sim 0.9931$ | **$0.9857 \sim 0.9973$** | 全6シナリオでカットオフモデルの方が順位相関 $\rho$ が向上し、パラメータ感度が低下。 |
| **調和中心性 $\rho$ 範囲** | $0.9937 \sim 0.9997$ | **$0.9967 \sim 0.9993$** | 両モデルとも $\rho > 0.993$ と極めて安定しており、時間制限の有無にほぼ依存しない。 |
| **基準値（$\rho \ge 0.95$）判定** | 全シナリオで適合 | 全シナリオで適合 | **時間制限の有無にかかわらず、「モデルがパラメータ摂動に対して頑健である」との結論は不変。** |

* **結論**: 時間制限（120分カットオフ）を導入しても、OAT感度分析の根本結論（3つの時間抵抗パラメータに対する中心性序列の高い頑健性と、`600m / 180s / 30s` の最適性）は一切損なわれない。むしろ媒介中心性においては、超長距離経路の連鎖的な経路転移（例：`penalty_300s` における本州〜北海道間の幹線転移）が120分圏内に局所化されるため、最低相関係数が $0.9617$ から $0.9857$ へと明確に改善した。

### 6.2 指標別の構造的挙動差と主データベースへの採用根拠

1. **調和中心性（Harmonic Centrality）の自然な距離減衰と収束性**:
   調和中心性は到達時間コストの逆数 $1/d(u,v)$ を加算するため、所要時間が120分（7,200秒）を超える遠隔駅の寄与度は極めて小さい。そのため、時間制限の有無にかかわらず上位駅構成（東京・神田・有楽町等の高密度都市圏中枢）およびパラメータ感度は高い水準で収束している。また、孤立成分や時間上限外の駅を $1/\infty = 0$ として一貫して処理できるため、従来の近接中心性のような分母歪みが生じない。
2. **媒介中心性（Betweenness Centrality）における国土形状バイアスの解消**:
   媒介中心性は距離減衰を持たないため、時間制限を設けない全域モデルでは、日常的には発生しない全国横断的な超長距離ODペアが本州中央部の東海道新幹線に集中し、豊橋（#4）・三河安城（#5）・掛川（#7）・浜松（#8）などの新幹線中間駅が都市圏巨大ターミナルを抑えて全国上位10駅を占める。一方、120分カットオフを導入することで、非現実的な超長距離ODが除外され、上野（#1）・大宮（#2）・品川（#3）・京都（#4）・新横浜（#5）・東京（#6〜#7）といった広域新幹線網と大都市圏通勤網の実際の結節ターミナルが上位に正しく抽出される。
3. **主データベース（`rail_network.sqlite`）における標準採用**:
   後続の駅類型化および乗降客数説明モデルで使用する他の評価指標（日常的な乗降客数・駅周辺人口）との空間スケールを整合させるため、主データベースの `station` テーブルには、パラメータ頑健性と実空間の拠点性の双方を兼ね備えた**120分カットオフモデル（新幹線巡航速度 200 km/h・在来線 50 km/h）に基づく媒介中心性および調和中心性**を正式採用する。
