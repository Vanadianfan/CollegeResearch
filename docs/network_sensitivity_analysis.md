# 鉄道網トポロジーのパラメータ感度分析：設計指針および検証結果

本稿では、運行系統ベースの在来線ネットワークにおける構造中心性（媒介中心性・調和中心性）のパラメータ依存性を単変量摂動法（One-At-a-Time: OAT）により検証し、基準パラメータ設定の妥当性と時間制限（120分カットオフ）および都市圏分離評価の有効性を整理する。

> **現行仕様（2026-11-18 更新）**
> - 本稿の実測値は、**新幹線・有料特急専用系統（JR成田エクスプレス）を除外した運行系統ネットワーク（`operational_line` / `operational_line_stop` 単位、全国 590 路線・10,442 停車駅・19,738 方向区間辺）** に基づく検証結果である。
> - 評価対象は **全国（`all`: 10,442 地点）・東京圏（`tokyo`: 2,038 地点・130 路線）・近畿圏（`kinki`: 1,425 地点・118 路線）** の 3 地域 × **時間制限なし（`unbounded`）／120分カットオフ（`cutoff`）** の 2 条件（計 6 データベース、[`network_sensitivity/`](../network_sensitivity)）で構成される。
> - 基準パラメータの公的資料・文献に基づく根拠および差異比較は [`docs/parameter_references.md`](./parameter_references.md) を参照。

### 1.3 移動コスト式と速度・迂回パラメータを固定する数理的根拠

経路 $P$（軌道リンク集合 $P_{\text{rail}}$、徒歩乗換リンク集合 $P_{\text{trans}}$、ただし $d_{\text{walk}}(e) \le D_{\text{trans}}$）の所要時間コスト $C(P)$ は次式で定義される。

$$
C(P) = \sum_{e \in P_{\text{rail}}} \left( \frac{d_{\text{rail}}(e)}{v_{\text{train}}} + T_{\text{stop}} \right) + \sum_{e \in P_{\text{trans}}} \left( \frac{\alpha \cdot d_{\text{walk}}(e)}{v_{\text{walk}}} + T_{\text{pen}} \right)
$$

1. **巡航速度（$v_{\text{train}}$）と時間ペナルティの双対性**:
   現行モデルでは新幹線除外により鉄道速度が一律（$v_{\text{train}}$）であるため、速度全体のスケール変動は正斉次性により $T_{\text{stop}}$ と $T_{\text{pen}}$ の相対重みを同時にスケーリングする操作と数理的に等価となる。したがって速度軸の感度は両ペナルティの摂動範囲に包含される。
2. **歩行速度（$v_{\text{walk}}$）と迂回係数（$\alpha$）の共線性・包含関係**:
   両者は常に単一の比 $\alpha / v_{\text{walk}}$ としてのみ作用するため完全に共線である。同一座標乗換（$d_{\text{walk}} = 0$）には影響せず、最大 $600\text{ m}$ の徒歩乗換における実用上の歩行ペース差も数十秒以内に収まるため、$T_{\text{pen}} \in [90\text{ s}, 300\text{ s}]$ の摂動実験により十分に網羅される。
3. **実質的自由度への集約**:
   以上より、経路選択と中心性序列を支配する独立した 3 変数（$D_{\text{trans}}, T_{\text{pen}}, T_{\text{stop}}$）に OAT 摂動を集約する。

## 2. 評価指標と算出・実行インターフェース

### 2.1 構造中心性の定義

[`centrality/calculate.py`](../centrality/calculate.py) に基づき、各評価領域の運行系統グラフ（総駅数 $N$）について 2 種類の正規化中心性を算出する（$d(s, t)$ は時間コスト最短所要時間、無制限モードでは時間上限なし）。

$$
C_B(v) = \frac{1}{(N - 1)(N - 2)} \sum_{s \neq v \neq t,\; d(s, t) \le T_{\text{cutoff}}} \frac{\sigma_{st}(v)}{\sigma_{st}},
\qquad
C_H(u) = \frac{1}{N - 1} \sum_{v \neq u,\; d(u, v) \le T_{\text{cutoff}}} \frac{1}{d(u, v)}
$$

### 2.2 感度分析の定量的評価指標

1. **スピアマン順位相関係数（$\rho$）**: 各領域の全停車駅（全国 10,442、東京圏 2,038、近畿圏 1,425 地点）における基準順位と摂動順位の相関を測定し、**$\rho \ge 0.95$** を「巨視的評価構造が頑健」とする判定基準に置く。
2. **Top-50 一致数および Jaccard 類似度（$J$）**: 上位 50 駅の重複駅数 $c$ と $J = |S_0 \cap S_k| / |S_0 \cup S_k| = c / (100 - c)$ により、主要拠点群の保存性と指標間の挙動差を評価する。
3. **最大順位変動量（$\Delta R$）および Top-50 外れ駅の新順位分布**: $\Delta R = R_{\text{baseline}} - R_{\text{alt}}$ の大きい特異駅を抽出して歪みメカニズムを特定するとともに、Top-50 から外れた駅がどの順位帯に留まっているかを検証する。

### 2.3 実行コマンド・格納スキーマ

```bash
# 全組合せ（{全国, tokyo, kinki} × {cutoff, unbounded}）を一括実行
python -m centrality.sensitivity --force

# 個別実行例
python -m centrality.sensitivity_cutoff --region tokyo --force
python -m centrality.sensitivity_unbounded --region kinki --force
```

出力 SQLite（[`network_sensitivity/*.sqlite`](../network_sensitivity)）は、いずれも `scenario`・`station_centrality_result`・`correlation_matrix` の 3 テーブルで統一されている。

  * **調和中心性**: 全国・東京圏では東京・有楽町・秋葉原・神田（山手線／京浜東北線）、近畿圏ではなんば・心斎橋・日本橋・大国町・天王寺・本町が不動の上位群を維持する。

### 4.2 2つの指標における Top-50 挙動の違い

全体の順位相関 $\rho$ は両指標とも高水準だが、上位 50 駅の顔触れ一致数では以下の構造的差異が現れる。

1. **調和中心性の連続的収束**:
   全 36 条件（3 地域 × 制限有無 × 6 シナリオ）で **$\rho = 0.9967 \sim 1.0000$**、120分制限下の Top-50 一致数も **38〜50 / 50駅**（近畿圏 `43〜50`、全国・東京圏 `38〜50`）と安定している。所要時間の逆数和による連続指標であるため、一部経路の変動が順位を急変させない（120分制限で 50 位を外れた駅も最大 `#117` まで）。
2. **媒介中心性における路線単位の纏まった入替え**:
   120分制限下の媒介中心性 Top-50 一致数は、**近畿圏 `42〜50` 駅**に対し**東京圏 `31〜48` 駅**・**全国 `26〜50` 駅**と下がり易い。これは媒介中心性が「最短経路に入るか否か」の離散的指標であり、同巡航速度（`50 km/h`）の並行路線が多い東京圏・全国では、停車ペナルティ変更により僅かな所要時間差が逆転すると**路線単位で数駅〜十数駅が纏めて Top-50 境界を跨ぐ**ためである。
   * **実測例（東京圏・120分制限・`stop_15s`）**: 一致数 `31/50` の内訳として、`東急東横線`（`10駅`：自由が丘・中目黒・多摩川・祐天寺等）と `JR京浜東北線`（`9駅`：大井町・蒲田・大森・川崎等）の計 `19駅` が一斉に Top-50 入りし、`JR総武本線`（`7駅`）・`JR中央本線`（`5駅`）等と入れ替わった。
   * **全国・120分制限・`stop_15s`**: 一致数 `26/50` でも、`東急東横線`（`12駅`）・`JR京浜東北線`（`10駅`）が一斉に上位 50 入りし、`JR総武本線`（`8駅`）・`JR中央本線`（`5駅`）・`JR神戸線`（`5駅`）等が押し出された構造である。
3. **Top-50 外れ駅の順位分布（順位崩落ではない根拠）**:
   120分制限の 3 地域合計で Top-50 から外れた延べ **`151件`**（全国 `58`、東京圏 `61`、近畿圏 `32`）を追跡すると、**`80.1%`（`121/151件`）が `89位以内`**、**中央値は `65.0位`**（全国 `66.5位`・東京圏 `65.0位`・近畿圏 `62.5位`、うち近畿圏は全 `32件` が `86位以内`）に留まっている。すなわち 50 位台後半〜80 位台への僅差移動にとどまり、拠点性の評価が崩落しているわけではない。

## 5. 時間制限有無の統合比較とモデル採用根拠

### 5.1 全 72 通り統合比較とカットオフ効果

3 地域（全国・東京圏・近畿圏）× 2 時間制限モード × 6 摂動シナリオ × 2 指標の全 **72 通り**について、基準値 $\rho \ge 0.95$ への適合状況を集約する。

| 評価領域・指標 | 時間制限なし（$\rho$ 範囲） | 120分カットオフ（$\rho$ 範囲） | 120分導入による改善効果 |
| :--- | :---: | :---: | :--- |
| **全国・媒介中心性** | $0.9803 \sim 0.9994$ | **$0.9900 \sim 0.9991$** | 最低相関が `+0.0097` 改善。 |
| **東京圏・媒介中心性** | $0.9435 \sim 0.9991$（※`stop_60s` のみ 0.9435） | **$0.9595 \sim 0.9990$** | 唯一の 0.95 未満シナリオが `0.9595` へ回復し全条件 $\ge 0.95$ 達成。 |
| **近畿圏・媒介中心性** | $0.9715 \sim 0.9982$ | **$0.9800 \sim 0.9993$** | 最低相関が `+0.0085` 改善し全条件 $\ge 0.98$ へ安定。 |
| **全 3 地域・調和中心性** | $0.9977 \sim 1.0000$ | **$0.9967 \sim 1.0000$** | 時間制限の有無を問わず全 36 条件で $\rho > 0.996$ を維持。 |

* **結論**:
  1. 全 72 通りのうち **71 通り（120分制限下では全 36 通り・100%）** で $\rho \ge 0.95$ を満たし、運行系統モデルにおいても順位構造の頑健性が確認された。
  2. 時間制限なしでは長距離連鎖によって路線単位の激しい順位転移（最大 8,000 位超）や都市圏内の相関低下（`0.9435`）が生じやすいのに対し、120分カットオフは評価を日常移動圏内に局所化して頑健性と拠点抽出の妥当性を同時に高める。

### 5.2 基準設定の位置づけと今後の課題

1. **主データベース（`rail_network.sqlite`）への標準採用**:
   [`centrality/calculate.py`](../centrality/calculate.py) により、`operational_line_stop` テーブルには基準設定（`600m / 180s / 30s / 120分制限`）に基づく全国指標（`betweenness_centrality`, `harmonic_centrality`）および東京圏・近畿圏の独立計算指標（`regional_betweenness_centrality`, `regional_harmonic_centrality`）を保存している。
2. **両極端の回避と公的資料による外挿確認**:
   内部検証により `300m/800m`・`90s/300s`・`15s/60s` の両側で実務上不自然なトポロジー歪みが起きることを確認しつつ、[`docs/parameter_references.md`](./parameter_references.md) および大都市交通センサス・不動産表示規約・国交省公開資料とも整合することを確認した（例：東京駅京葉線等の連絡距離 `565〜600m`、乗換平均 `4分強` から徒歩分を除いた固定抵抗 `180s`、都市鉄道表定速度帯・基本停車時分、三大都市圏平均片道通勤時間 `62〜68分` を包絡する `120分` 上限）。
3. **限界と次段階（外部妥当性検証）**:
   パラメータ同士の感度分析と公的基準の照合だけでは、基準点周辺の微小範囲から最適値を一意に絞り切ることはできない。今後は実測の 2024 年乗降客数（`station_group.passengers`）や 250 m メッシュ周辺人口（`population_mesh.sqlite`）・迂回距離コストと突き合わせることで外部妥当性を検証し、駅の類型化へ進む。
