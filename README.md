# **研究内容**

本研究では、ある都市または都市圏の鉄道駅を対象とし、乗降客数、ネットワーク中心性、周辺人口、迂回距離コストといった四つの指標を用いて、複数の観点から駅の重要性を評価する。

本研究は、各指標が互いに独立していることを前提とし、従来の単一の指標のみによって駅の重要度を判断したりするものではない。寧ろ、複数の指標の間に見られる一致と乖離を分析し、それに基づいて駅の類型化を行うことを目的とする。

なお、データの時点は原則として **2024年のデータに統一**し、年次差による影響をできるだけ排除する。

また、分析上の駅の単位は「駅名」そのものに限定せず、**乗換可能な駅群（統合駅）の実態を反映したトポロジー**として扱う。具体的には、各路線の駅を独立したノードとして保持しつつ、徒歩連絡可能な駅間に乗換リンクを付与し、乗換時間コストを考慮することで、都心部における過度な瞬間移動（連鎖的統合）を防ぎながら実態に近い評価を行う。

---

# **研究の対象者・意義**

本研究は、鉄道事業者や行政機関が、駅の重要性や鉄道ネットワークの脆弱性を把握する際の基礎資料となることを想定している。

乗降客数だけでは、利用者は多くなくても、運休時に大きな迂回を生じさせる駅や、周辺人口に対して重要な役割を持つ駅を見落とす可能性がある。そこで、乗降客数、構造中心性、周辺人口、迂回距離コストを比較し、駅がどのような意味で重要であるかを類型化する。

これにより、設備維持、障害時対応、代替交通の検討などにおいて、単一指標では把握しにくい駅の特徴を示すことを目指す。

# **研究プラン**

## **評価指標**

本研究では、研究対象地域内の駅について、以下の四つの観点から評価を行う予定である。

### **0. 乗降客数**

各駅の乗降客数を対数変換した上で標準化し、駅の実際の利用規模を表す指標として用いる。

### **1. 構造中心性**

グラフ理論における中心性指標を用いて、鉄道ネットワーク構造における駅の位置づけを評価する。

路線間の乗換リンク（600m以内）および移動・乗換時間コストを付与した加重ネットワークを構築し、**時間コスト最短経路に基づく媒介中心性（Betweenness Centrality）**および近接中心性（Closeness Centrality）を算出する。これにより、純粋な幾何距離ではなく、実際の所要時間構造における要衝駅を特定する。

### **2. 周辺人口**

駅周辺の人口に基づき、駅が有する潜在的なサービス人口を評価する。

具体的な方法としては、道路距離を基準とし、駅と人口分布地点との距離に応じて人口を逓減的に重みづけする方法を検討する。

### **3. 迂回距離コスト**

各駅が利用不能になった場合のネットワーク変化を模擬することで、その駅が鉄道ネットワーク全体の到達可能性に与える影響を評価する。

具体的には、

1. 各駅を一つずつ除去する
2. 除去後のネットワークにおいて全駅間の最短経路を再計算する

その上で、当該駅の除去によって生じる迂回時間コストを算出する。評価にあたっては、到達可能ODの所要時間増分（迂回コスト）と、路線切断による到達不能需要（ネットワーク損失）を区別して整理する。

## **データ整備方針（共通前処理）**

### **年次の統一**

各指標の比較可能性を確保するため、入手可能な範囲で **2024年時点のデータに統一**して分析する（例：駅別乗降客数、人口メッシュ、鉄道データなど）。

### **駅の接続と乗換リンク（600mルールと時間コスト）**

改札外乗換や近接駅の実態を反映するため、元の駅グループのみに依存せず、**測地距離600m以内の駅間に双方向の乗換リンクを動的に生成**する。

1. **距離の補正**：
緯度による経度方向の歪みを排除した上で**ユークリッド**距離（m）を算出する。

$$
乗換時間コストの定義：
T_{\text{transfer}} = \frac{\text{距離} \times \alpha}{v_{\text{walk}}} + T_{\text{penalty}}
$$

- 歩行速度 $v_{\text{walk}} = 80\text{ m/min}$（約 1.33$\text{ m/s}$）、迂回係数 $\alpha = 1.2$。
- 固定乗換ペナルティ $T_{\text{penalty}} = 180\text{ 秒}$（3分：改札通過、階段昇降、平均待機時間）。
1. **同位置接続（d = 0）の特例**：
異なる路線が完全に同一座標に乗り入れている場合、純歩行時間成分は 0 とするが、固定乗換コスト（180秒）は同様に適用する。

## **任意の改善項目**

鉄道ネットワークモデルをより実際の交通状況に近づけるため、データの取得可能性および実装難度を考慮しつつ、以下の修正を加えることを検討する。

### **乗換および路網表現**

駅ノードを路線ごとに保持し、既有の線路接続と生成した乗換リンクを統一した経路探索グラフとして扱う。

- **経路表現**：既有の統合線路区間は「接続ID（リンク番号）」、乗換区間は「`駅ID1-駅ID2`」として識別・出力する。

### **列車走行時間コストと停車ペナルティ**

列車は一定の平均速度で巡航すると仮定し、隣接駅間の移動時間に停車・加減速ペナルティを加味する。

$$
T_{\text{rail}} = \frac{\text{駅間距離}}{v_{\text{train}}} + T_{\text{stop}}
$$

- 電車巡航速度 $v_{\text{train}} = 50\text{ km/h}$（約 13.89$\text{ m/s}$）。
- 停車ペナルティ $T_{\text{stop}} = 30\text{ 秒}$（停車時間固定 10 秒 ＋ 加減速損失 20 秒）。各接続リンクの通過が自動的に1駅停車を意味するため、静的な辺重みとして組み込む。

### **優等列車の扱い**

快速、急行、特急などの優等列車については、その停車駅間を接続する特殊リンクを追加することを検討する。

これにより、優等列車の停車駅が実際の交通サービスにおいて有する相対的に高い重要性を反映する。

### **運行本数と運行間隔**

平均運行間隔に基づいてリンクの重みを調整することを検討する。

例えば、運行本数が多い区間には低い待ち時間コストを設定し、運行本数が少ない区間には高い待ち時間コストを設定することで、実際の交通利便性の違いを反映する。

# **研究目標**

## **主線：駅の類型化**

本研究の主線は、各指標の間に見られる一致と乖離を分析し、その特徴に基づいて駅を類型化することである。

例えば、以下のような類型が考えられる。

- **構造的拠点型**：ネットワーク中心性が高く、鉄道ネットワーク全体の連結性に与える影響も大きい駅。
- **潜在的脆弱型**：乗降客数は必ずしも多くないが、利用不能になった場合に大きな迂回距離コストを生じる駅。
- **人口サービス型**：周辺人口が多く、高い潜在的サービス価値を有する駅。
- **高利用型**：乗降客数は多いが、ネットワーク構造上の重要性は必ずしも同程度に高くない駅。

このような類型化を通じて、単一の指標だけでは見落とされ易い駅の特徴を明らかにし、各類型の駅が鉄道ネットワークにおいて持つ意味を考察する。

## **発展分析**

### **1. 総合重要度指標の構築**

四つの指標に基づき、総合的な評価指標を構築することを検討する。この指標を仮に「総合重要度」と呼ぶ。

この指標は、駅の類型化結果を補完し、単一指標では把握しにくい潜在的に重要な駅を見出すために用いることができる。

### **2. 乗降客数説明モデル**

構造中心性、周辺人口、迂回距離コストなどの指標に基づいて、乗降客数説明モデルを構築することを検討する。この場合、実際の乗降客数を被説明変数として用いる。

この分析により、特定の都市または都市圏において、どのような要因が駅の実際の利用規模をよりよく説明するのかを検討することができる。

### **3. 乗降客数増加率モデル**

複数年度の乗降客数データを取得できる場合には、乗降客数増加率モデルを構築することも検討する。

具体的には、年度間の乗降客数の対数差を被説明変数とし、駅の特徴と乗降客数変化との関係を分析する。

この分析は、駅利用の変化傾向を理解し、将来的な資源配分や交通サービス調整の方向性を検討する上での参考となる。

# **研究データ**

- **国土数値情報「鉄道データ」**：鉄道路線や駅の位置情報を取得し、鉄道ネットワークを作成するために利用を検討しています。
https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2025.html
- **国土数値情報 「駅別乗降客数データ」**：各駅の乗降客数を取得するために利用を検討しています。
https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-S12-2024.html
- **e-Stat「統計地理情報システム 地域メッシュ統計」**：駅周辺人口を計算するために、国勢調査の500mメッシュや1kmメッシュの人口データを利用することを検討しています。
https://www.e-stat.go.jp/gis/statmap-search?page=1&toukeiCode=00200521&type=1
- **OSMnx / OpenStreetMap**：道路ネットワーク上の距離を用いて駅周辺人口を評価する場合に、道路ネットワークデータの取得や最短経路計算の補助として利用を検討しています。
https://osmnx.readthedocs.io/
